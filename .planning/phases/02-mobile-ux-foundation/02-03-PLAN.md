Найти div-обёртку по `className="flex rounded-lg overflow-hidden border border-[var(--color-border)] text-[12px]"`.

Изменить обёртку (убрать `overflow-hidden`):
```tsx
// Было:

```
СТОП — overflow-hidden нужен для border-radius на крайних кнопках. Вместо этого перенести border-radius на сами кнопки:
```tsx
// Обёртка: убрать rounded-lg и overflow-hidden
<div className="flex border border-[var(--color-border)] text-[12px]">

// Person button — добавить min-h-[48px] flex items-center justify-center, добавить rounded-l-lg:
className="px-3 min-h-[48px] flex items-center justify-center font-medium transition-colors rounded-l-lg"

// Company button — добавить min-h-[48px] flex items-center justify-center, добавить rounded-r-lg:
className="px-3 min-h-[48px] flex items-center justify-center font-medium transition-colors rounded-r-lg border-l border-[var(--color-border)]"
```
style на кнопках остаётся без изменений (background и color управляются через style prop).

**3. Search icon button (lines ~140-153):**

Найти кнопку по `className="absolute right-2 top-1/2 -translate-y-1/2 p-1 rounded-md"`. Заменить:
```tsx

// Стало (per D-08 — min-h и min-w 48px, flex centering):
className="absolute right-2 top-1/2 -translate-y-1/2 min-h-[48px] min-w-[48px] flex items-center justify-center rounded-md"
```
style остаётся без изменений.
